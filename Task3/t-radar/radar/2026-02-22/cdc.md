# Change Data Capture (CDC)

Техника захвата изменений в реальном времени из баз данных.

## Использование в компании
Ключевая технология для миграции с Legacy DWH без остановки бизнеса. Захватываем изменения в SQL Server 2008 и передаем в новую облачную шину.

## Преимущества
- Минимальное воздействие на работающую систему
- Гарантия доставки изменений
- Возможность постепенного отключения Legacy
