# Apache Kafka / Confluent

Облачная шина данных для обмена событиями между доменами.

## Текущий статус
Разворачиваем как центральную шину событий. Пилот на доменах Клиники и Финтех.

## Возможности
- Гарантированная доставка сообщений
- Масштабирование до миллионов событий в секунду
- Хранение потока событий для воспроизведения
