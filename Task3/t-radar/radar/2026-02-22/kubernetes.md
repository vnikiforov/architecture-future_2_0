# Kubernetes

Оркестрация контейнеров для микросервисов и ИИ-нагрузок.

## Использование
- Развертывание ИИ-сервисов с поддержкой GPU
- Управление микросервисами финтех-домена
- Единая платформа для всех новых разработок

## Преимущества
- Автоматическое масштабирование под нагрузку
- Единообразие сред (dev/stage/prod)
- Самовосстановление при сбоях
