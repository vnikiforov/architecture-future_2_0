# Python

Основной язык для ИИ-сервисов, анализа данных и прототипирования.

## Использование в компании
Data Science команда активно использует Python для разработки моделей диагностики, обработки медицинских снимков и исследовательских задач.

## Причины сохранения
- Богатая экосистема библиотек для машинного обучения (TensorFlow, PyTorch, scikit-learn)
- Активное сообщество и поддержка
- Наличие компетенций в команде
