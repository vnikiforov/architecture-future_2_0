# Microsoft Azure

Основная облачная платформа компании.

## Использование
- Размещение доменных витрин данных
- Хостинг микросервисов
- Геораспределенное резервирование критичных систем

## Преимущества
- Соответствие требованиям регуляторов для медицинских и финансовых данных
- Гибкое масштабирование ресурсов
- Интеграция с существующими Microsoft-продуктами
