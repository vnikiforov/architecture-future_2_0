# Data Mesh

Архитектурный подход с децентрализацией данных по доменам.

## Текущий статус
Пилотируем на доменах «Клиники» и «Финтех».

## Бизнес-ценность
- Обеспечивает независимость развития подразделений
- Позволяет подключать новые бизнесы (Фарма, Электроника) без изменения центрального DWH
- Ускоряет time-to-market для новых продуктов

## Использование в компании
Внедряется в рамках трансформации архитектуры данных. Первые пилоты запланированы на Q2 2026.
