# dbt (data build tool)

Инструмент для трансформации данных в доменных витринах.

## Возможности
- SQL-модели с версионированием
- Автоматическое тестирование данных
- Генерация документации
- Прозрачность преобразований

## Статус
Изучаем для внедрения в доменах как стандартный инструмент трансформации. Планируем пилот в домене «Клиники».
