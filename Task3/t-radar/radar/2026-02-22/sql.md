# SQL (T-SQL)

Язык запросов, активно используемый в текущем DWH на SQL Server 2008.

## Текущее состояние
SQL остается основным инструментом для работы с данными в Legacy-системе.

## План изменений
В новой архитектуре SQL не исчезнет полностью, но перестанет быть единственным инструментом для бизнес-логики. Бизнес-логика будет выноситься в доменные сервисы, а SQL останется для трансформаций в витринах данных (через dbt).
