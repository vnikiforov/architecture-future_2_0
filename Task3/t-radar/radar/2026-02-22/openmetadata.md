# OpenMetadata / DataHub

Инструменты каталогизации данных и управления метаданными.

## Назначение
- Поиск данных бизнес-пользователями
- Отслеживание происхождения данных (data lineage)
- Управление качеством данных
- Документирование схем

## Статус
Проводим сравнение решений для выбора стандарта компании.
