# SQL Server 2008 (on-prem)

Текущее DWH, в котором хранятся все исторические данные компании.

## Риски
- **Безопасность:** Прекращена поддержка производителем, новые уязвимости не закрываются
- **Производительность:** Не масштабируется под текущие объемы (сотни терабайт)
- **Технический долг:** Отсутствие современных возможностей (in-memory, columnstore)

## План
1. Подключаем CDC для репликации изменений в облако
2. Переводим оперативные отчеты на доменные витрины
3. Переводим DWH в режим "холодного хранилища" для аудита
4. Полное отключение после завершения миграции
